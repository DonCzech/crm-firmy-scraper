# beauty-02 — Séra Beauty

**Autor:** Webero (Claude) · **Licence:** interní šablona Webero
**Zdrojový web (DNA):** beautycentral.cz (migrace klienta z WordPressu — charakter povýšen na award-winning, obsah demo/brand-neutral)

## Charakter
Městské beauty & wellness studio ve večerním městském duchu ("absolutní relax v centru města", otevřeno do 22:30). Warm earthy spa vibe.

- **Paleta:** coffee brown `#523E35` (accent/CTA), olive-black `#1A210F` (nadpisy), warm muted `#6B5D52`, cream/white, tmavý footer `#2A211C`.
- **Typografie:** Montserrat 800 display (`var(--font-montserrat)`) — velké tučné nadpisy s tight tracking; Montserrat 400 body.
- **Motiv:** 💎 diamantový monogram, hairline oddělovače, foto koláže, grayscale→color hover.
- **Rytmus:** cinematic full-bleed hero → světlá about (foto koláž) → service carousel (3 kategorie) → tmavý footer.

## Sekce (home)
navbar (`beauty-02-nav`) → hero (`hero-beauty-02`) → about (`about-beauty-02`) → services (`beauty-02-carousel`) → footer (`beauty-02-footer`).
