**Použití:** Závazné mapování `original-slug → engine-slug + demo název` pro všech 91 šablon. Sonnet při FÁZI C použije:
- **Engine slug** jako `src/templates/<engine-slug>/` adresář a `<engine-slug>-v2` DB tenant

Pravidla:
- Demo jména **nesouvisí** s originálem (žádné přechody jako thebarber → The Barber).
- Engine slug = `<kategorie>-NN` — generický, snadno řaditelný.
